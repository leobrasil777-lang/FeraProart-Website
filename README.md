# Fera Proart

Site institucional desenvolvido para a Fera Proart, empresa de uniformes, calçados e acessórios para bandas, fanfarras e corporações.

**Site:** https://www.feraproart.com.br

## Sobre o projeto

Aplicação front-end de página única, com páginas institucionais e de produtos, navegação por rotas, metadados de SEO por página e chamadas para contato pelo WhatsApp.

## Tecnologias

- React 19
- TypeScript
- Vite
- React Router
- CSS

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para validar a compilação de produção:

```bash
npm run build
npm run preview
```

## Estrutura

- `src/pages`: páginas do site e suas seções
- `src/components`: componentes compartilhados
- `src/assets`: imagens e ícones
- `src/utils`: funções de analytics e contato
